# SoC speedup: software CNN vs. accelerator on PicoRV32

Generated by `scripts/soc_speedup.py` from the bench firmware (`firmware/apps/bench`) running on the RTL simulation of the whole SoC (`soc_top`, Verilator), 4 quick-subset image(s). Cycle counts are the CPU's `rdcycle` (spec §13.9). Both the software CNN's and the accelerator's logits equal the golden model's for every image. Times assume the 50 MHz board clock.

Firmware compiler: riscv64-unknown-elf-gcc (14.2.0+19) 14.2.0, `-O2`, RV32IM; PicoRV32 with the fast multiplier (spec §13.2).

The software CNN retires 2,383,369 instructions per image at 7.55 cycles per instruction. PicoRV32 is a multi-cycle core without caches: every instruction fetch and data access is an AXI4-Lite transaction to the RAM. The speedup is that of this SoC with and without its accelerator; a CPU with tightly coupled memory or caches would run the software faster.
