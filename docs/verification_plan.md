# Verification plan

Feature → test(s) → coverage item(s) → status. Kept current every phase.
Reference: `model/golden.py` + `model/hwmap.py` + committed `model/artifacts/` (`docs/spec.md` §3–§9).

Status values: **done** (test exists and passes in CI), **planned** (phase in brackets),
**gap** (known hole, with reason).

CI has two workflows: `ci.yml` on every push (ruff, RTL lint, every unit test, the system tests
not marked `full`, script and model tests; four parallel jobs, under 10 minutes) and `full.yml` (every test,
formal proofs included; nightly and on manual trigger). "In CI" means the full job; checkpoints
require it to be green for HEAD. Tests marked `full` (slow): the Icarus `accel_top` runs
(`quick-2`, `xcheck-1`), `test_soc[demo]` and `test_soc_bench`.

## 8. UVM testbench (Phase 6; Verilator + uvm-core, D-050 to D-052)

`testbench/uvm/`: an AXI4-Lite agent (`axil_pkg`), a register model of the CSR map, a
busy-aware scoreboard that checks every response and every read whose value is determined
(D-052; per-run counts of checked and unpredictable reads in
`testbench/reports/uvm_checks.md`), functional coverage, and seven tests on `accel_axil_tb`
(accelerator slave + `accel_top`, no init files). Run by `pytest testbench/uvm` with one fixed
seed per test (fast CI job and full CI job) and with 10 random seeds per test (`UVM_SEEDS=10`,
full CI job, nightly); a test passes only with exit 0, no UVM_ERROR / UVM_FATAL / UVM_WARNING
and its own TEST PASSED line, which requires a minimum of checked reads, runs and golden-checked
runs.
